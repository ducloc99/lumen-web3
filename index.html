The Protocol

Three decisions that made it this fast.

01 · CONSENSUS

Parallel finality

Non-conflicting transactions settle in parallel lanes instead of one global queue — most blocks never touch each other at all.

02 · VALIDATION

Pruned state proofs

Validators verify against a compressed state root, not full history — the chain gets faster as it gets older, not slower.

03 · SETTLEMENT

Rollup to L1 hourly

Batched proofs settle to the base layer every sixty minutes — fast enough to trust, cheap enough to run continuously.
